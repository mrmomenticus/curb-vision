# curb-vision

**CurbVision** — экспериментальная система компьютерного зрения для мониторинга уличных парковок и обнаружения свободных мест вдоль дороги с помощью камеры.

В отличие от классических парковочных систем, проект ориентирован на участки дороги, где **нет фиксированной разметки отдельных парковочных мест**. Основная задача — определить расположение припаркованных автомобилей, оценить свободное пространство между ними и понять, достаточно ли его для парковки.

## Цели проекта

- Обнаружение припаркованных автомобилей на изображении с камеры.
- Определение занятых и свободных участков вдоль дороги.
- Оценка длины свободного пространства с учётом перспективы камеры.
- Определение возможности парковки автомобиля заданной длины.
- Визуализация результатов анализа на изображении.
- Экспериментальное исследование алгоритмов Computer Vision.

## Особенности

Проект разрабатывается с учётом следующих условий:

- **Нефиксированные парковочные места:** автомобили могут парковаться с произвольными интервалами.
- **Перспективное изображение:** камера расположена выше дороги и направлена под углом.
- **Наклон дороги:** парковочная зона может находиться на участке с продольным уклоном.
- **Различные условия наблюдения:** освещение, тени, частичные перекрытия автомобилей и погодные условия.

### 1. Получение изображения

Получение кадров с USB/IP-камеры или из предварительно записанного видео.

### 2. Обнаружение автомобилей

Поиск припаркованных автомобилей с использованием алгоритмов компьютерного зрения.

Возможные подходы:
- Object Detection (YOLO или аналогичные модели).
- Object Tracking для отслеживания автомобилей между кадрами.
- Сегментация объектов для более точного определения их границ.

### 3. Анализ парковочной зоны

Выделение области дороги, в которой разрешена парковка, и определение занятых участков.

### 4. Геометрическая коррекция

Учёт перспективных искажений с использованием калибровки камеры и геометрических преобразований.

Для оценки реальных расстояний предполагается использовать плоскую модель дорожного покрытия, гомографию и/или дополнительные калибровочные данные. Для дороги с существенным изменением уклона может потребоваться более сложная геометрическая модель.

### 5. Поиск свободного пространства

Определение интервалов между припаркованными автомобилями и оценка их размеров.

Свободный участок считается потенциально пригодным для парковки, если его размеры соответствуют заданным требованиям с учётом необходимых зазоров.

## Метрики качества

Для оценки алгоритмов планируется использовать:

- **Precision / Recall** — качество обнаружения автомобилей.
- **MAE (м)** — средняя абсолютная ошибка оценки длины свободного пространства.
- **Parking Availability Accuracy** — точность классификации участков как пригодных или непригодных для парковки.
- **FPS / Latency** — производительность обработки изображений.
